# Update Ring Design

| Ring | Membership | Deferral | Purpose |
|---|---|---:|---|
| Preview | IT test devices | 0 days | Detect compatibility problems early |
| Pilot | Cross-functional representatives | 3 days | Validate business applications and peripherals |
| Broad | Remaining managed devices | 10 days | Controlled organisation-wide deployment |
| Critical exceptions | Approved systems only | Defined per risk | Temporary exception with owner and expiry |

## Gates

- update is approved for the OS version
- monitoring and rollback contacts are known
- pilot covers critical applications and hardware
- minimum free disk space is confirmed
- encryption recovery data is available
- user communication is scheduled
- exception records have an expiry

## Success criteria

Patch success is not only installation. Devices must check in, report the expected build, retain healthy security controls and pass agreed business-application checks.
