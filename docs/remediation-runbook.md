# Patch Compliance Remediation Runbook

1. Verify device identity, ownership and last check-in.
2. Confirm the applicable update ring and policy.
3. Check power, storage, network and pending-restart state.
4. Review update history and error codes.
5. Compare with known issues for the relevant build.
6. Retry sync or installation only through an approved process.
7. Protect BitLocker recovery and business data before high-impact repair.
8. Escalate repeated failures with logs and attempted actions.
9. Confirm the new build and application health.
10. Record the result, exception or next evaluation date.

Retire, reset and wipe actions are deliberately outside the scripts in this repository because they require ownership verification and explicit approval.
